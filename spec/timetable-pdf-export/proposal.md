# Timetable PDF export

User request: a polished timetable PDF export. The three layouts are class whole week, teacher whole week and full school.

Latest user clarification: export uses the selected school and schedule. With a class selected, export only that class's complete week; a selected teacher must not narrow it. With only a teacher selected, export that teacher's complete week. With neither class nor teacher selected, export the full school. Class takes priority when both are selected.

The existing screen selectors determine the export directly; a separate export chooser is unnecessary. Retain readable layouts, full lesson details and draft labels. Day, room, subject, period and search controls do not alter the whole-week scope defined by the four named selectors.

Latest layout clarification: keep the existing class and teacher weekly layouts. Full school is a convenience download combining every class weekly timetable into one PDF, each class beginning on a new page, instead of a separate school overview.
